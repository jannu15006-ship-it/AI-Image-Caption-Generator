# AI Caption Generator

A Day 1 Streamlit app that lets users upload an image, choose a platform and tone, and generate a caption using Anthropic Claude Vision.

## Features

- Image upload support for JPG, JPEG, PNG, and WEBP
- Platform selector for Instagram, Twitter/X, LinkedIn, YouTube, and General
- Tone selector for Funny, Emotional, Inspirational, Viral, Professional, and Poetic
- API key input with password masking
- Generated caption display with a copy-to-clipboard button
- Basic error handling for invalid images and API failures

## Setup

1. Create and activate a Python environment.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the app:

```bash
streamlit run app.py
```

## API Key

Enter your Anthropic API key in the app when prompted. Keep the key private and do not commit it to source control.
